# Minimal Synthetic GRIB2 Message - Buffer Underrun Test Fixture

## Purpose

This is a synthetic GRIB2 message designed to trigger the buffer underrun vulnerability in gribtract with the smallest possible file size.

## File Information

- **Path:** `crates/gribtract/tests/corpus/small/minimal_synthetic_underrun.grib2`
- **Size:** 104 bytes
- **Structure:** Minimal GRIB2 message with only essential sections (0, 1, 3)

## Section Structure

```
Section 0 (Indicator): bytes 0-15 (16 bytes)
  - Magic: "GRIB"
  - Discipline: 0 (Meteorological)
  - Edition: 2 (GRIB2)
  - Total length: 104 bytes (8 bytes, u64be as read by gribtract)

Section 1 (Identification): bytes 16-36 (21 bytes)
  - Minimal identification data
  - Mostly padding zeros

Section 3 (Grid Definition): bytes 37-103 (67 bytes available, claims 72)
  - THE BUG TRIGGER
  - Claims 72 bytes in length field
  - Only 67 bytes actually available
  - 5-byte shortage triggers buffer underrun
```

## The Vulnerability

**Error triggered:** `range end index 109 out of range for slice of length 104`

**How it works:**
1. Parser reads Section 3 header claiming 72 bytes
2. Parser calculates Section 3 body will span bytes 42..109
3. File only contains 104 bytes total
4. Byte 109 is out of bounds → panic/underrun

**Root cause:** Section 3 length field (72 bytes) exceeds actual available data (67 bytes)

## Usage

To trigger the buffer underrun:

```bash
cargo run --bin gribtract -- decode crates/gribtract/tests/corpus/small/minimal_synthetic_underrun.grib2
```

Expected result: Panic with "range end index 109 out of range for slice of length 104"

## Essential vs Non-Essential Sections

Based on section essentiality analysis:

**Essential for bug trigger:**
- Section 0: Required for GRIB2 recognition
- Section 1: Required for parser initialization
- Section 3: **THE TRIGGER** - Length mismatch causes underrun

**Non-essential (removed to minimize size):**
- Section 2 (Local Use): Not needed
- Section 4 (Product Definition): Never reached due to Section 3 failure
- Section 5 (Data Representation): Never reached
- Section 6 (Bit-map): Never reached
- Section 7 (Data): Never reached

## Creation Method

Generated by Python script that:
1. Creates Section 0 with proper GRIB2 structure
2. Creates minimal Section 1 (21 bytes, mostly padding)
3. Creates Section 3 with intentional length mismatch (claims 72, provides 67)
4. Updates total length in Section 0
5. Writes binary output
