# GFS Gaussian-Grid Fixture Structure

## Overview

GFS (Global Forecast System) Gaussian-grid fixtures are GRIB2 messages that use **Grid Definition Template 3.40 (GDT 40)** — Gaussian Latitude/Longitude grids. These grids have uniform longitude spacing but non-uniform latitude spacing based on Gaussian quadrature, providing optimal numerical properties for spectral weather models.

## Key Fixtures

### 1. `core_gaussian_gdt40` — T254 Gaussian Grid
- **Source**: NOAA CORe (Climate Data Record) Archive
- **File**: `flx.2024011500.grib2`
- **Golden**: `tests/corpus/golden/core_gaussian_gdt40.json`
- **Size**: 10.5 MiB (remote), 131,072 grid points
- **Grid**: 512 × 256 (T254, N=128)
- **Coverage**: Global flux analysis (radiative, heat fluxes, land surface, soil conditions, cloud layers)

### 2. `gfs_gaussian_gdt40_t1534` — T1534 Gaussian Grid
- **Source**: NOAA GDAS Surface Flux
- **File**: `gdas.t00z.sfluxgrbf000.grib2`
- **Size**: 122 MiB (remote), 4,718,592 grid points
- **Grid**: 3072 × 1536 (T1534, N=768)
- **Coverage**: High-resolution global surface flux analysis (~12 km resolution)
- **Status**: ✅ Fully supported by gribtract (verified 2026-07-24)

## Key Components and Fields

### 1. Grid Definition (GDT 3.40)

The Gaussian grid is defined in the `grid` object with **template: 40**:

| Field | Type | Description | Example |
|-------|------|-------------|---------|
| `template` | integer | Grid Definition Template number (40 = Gaussian Lat/Lon) | 40 |
| `num_data_points` | integer | Total number of grid points (nx × ny) | 131072 |
| `nx` | integer | Number of points along longitude (x-direction) | 512 |
| `ny` | integer | Number of points along latitude (y-direction) | 256 |
| `lat_first` | float | Latitude of first grid point (degrees, ±90) | 89.4629 |
| `lon_first` | float | Longitude of first grid point (degrees, 0–360) | 0 |
| `lat_last` | float | Latitude of last grid point (degrees, ±90) | -89.4629 |
| `lon_last` | float | Longitude of last grid point (degrees, 0–360) | 359.297 |
| `di` | float | Longitude increment (degrees, uniform spacing) | 0.703125 |
| `dj` | float | Latitude increment (null for Gaussian grids, computed) | null |
| `scanning_mode` | integer | Bit field for scan direction (0 = +i, -j) | 0 |
| `resolution_flags` | integer | Bit flags for grid resolution | 48 |
| `shape_of_earth` | integer | Earth shape code (6 = WGS84) | 6 |

### 2. Gaussian Grid Parameters

The Gaussian grid's N parameter (number of parallels from pole to equator) is implicit in the grid dimensions:

- **N (parallels)** = `ny / 2` for full global grids
- **T-number** = 2N (triangular truncation)
- **Latitude spacing**: Non-uniform, following zeros of Legendre polynomial P_N
- **Longitude spacing**: Uniform (`di` field)

#### Gaussian Grid Examples

| T-Number | N | nx (lon) | ny (lat) | Resolution |
|----------|---|----------|----------|------------|
| T254 | 128 | 512 | 256 | ~0.7° (~70 km) |
| T1534 | 768 | 3072 | 1536 | ~0.12° (~12 km) |

## Special Characteristics

### Gaussian Latitude Distribution

Gaussian grids use **non-uniform latitude spacing** based on Gaussian quadrature:

- Latitudes are the zeros of the Legendre polynomial P_N(sin φ)
- Provides optimal numerical properties for spectral models
- Spacing is denser near poles and equator, sparser at mid-latitudes
- Total parallels = 2N (pole-to-pole) or 2N+1 (including poles)

**Approximation in gribtract**: The current implementation approximates latitude spacing as linear between `lat_first` and `lat_last` for nearest-point queries. This is exact at grid corners and provides a reasonable approximation elsewhere. True Gaussian quadrature placement would require computing Legendre polynomial zeros — a valid optimization for future work.

### Grid Extents and Resolution

#### T254 (core_gaussian_gdt40)
- **Latitude range**: 89.4629°N to -89.4629°S
- **Longitude range**: 0°E to 359.297°E
- **Longitude increment**: 0.703125° (~70 km at equator)
- **Total points**: 131,072 (512 × 256)
- **N parameter**: 128 parallels (pole to equator)

#### T1534 (gfs_gaussian_gdt40_t1534)
- **Latitude range**: 89.910324° to -89.910324°
- **Longitude range**: 0.000000° to 359.882813°
- **Longitude increment**: ~0.117° (~12 km at equator)
- **Total points**: 4,718,592 (3072 × 1536)
- **N parameter**: 768 parallels (pole to equator)

### Center and Subcenter

- **Center 7**: US National Weather Service (NCEP) — standard for GFS products
- **Subcenter 3**: Specific NCEP center designation
- **Subcenter 0**: Generic NCEP (also common)

Golden reference fixtures are generated using `scripts/gen_golden.py` from source GRIB2 files via:

- **NOMADS**: NOAA operational data access
