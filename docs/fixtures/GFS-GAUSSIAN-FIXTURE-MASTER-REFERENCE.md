## Overview

This master reference provides comprehensive documentation for GFS (Global Forecast System) Gaussian-grid fixtures used in gribtract testing and validation. GFS Gaussian-grid fixtures use **Grid Definition Template 3.40 (GDT 40)** — Gaussian Latitude/Longitude grids with uniform longitude spacing and non-uniform latitude spacing based on Gaussian quadrature.

### Why Gaussian Grids?

Gaussian grids provide optimal numerical properties for spectral weather models:
- **Non-uniform latitude spacing**: Based on Gaussian quadrature points (roots of Legendre polynomials)
- **Spectral model compatibility**: Used in global spectral models (FV3GFS, ECMWF IFS)
- **Pole-to-pole coverage**: Extends nearly to the poles, avoiding singularities
- **Optimal integration**: Provides exact numerical integration for spherical harmonics

## Gaussian Grid Parameters

### T-Number Resolution

| T-Number | N | nx | ny | Points | Approx Resolution |
|----------|---|----|----|---------|-------------------|
| T62 | 62 | 192 | 128 | 24,576 | ~1.875° |
| T254 | 128 | 512 | 256 | 131,072 | ~0.703° |
| T574 | 192 | 768 | 384 | 294,912 | ~0.469° |
| T1534 | 768 | 3072 | 1536 | 4,718,592 | ~0.117° |

**Key parameters:**
- **N**: Number of Gaussian latitudes from equator to pole
- **Total latitudes**: `2N` (pole to pole)
- **Longitude points**: Typically `4N` (power of 2)
- **Resolution**: ~`360° / nx`

### Gaussian Latitude Distribution

Gaussian latitudes are **not evenly spaced** — they are computed as the roots of Legendre polynomial P_N:

- **Equator**: Wider spacing (cluster around 0°)
- **Mid-latitudes**: Moderate spacing
- **Poles**: Narrower spacing (cluster near ±90°)

This distribution provides optimal numerical integration for spectral models.

## Special Characteristics

### 1. Non-Uniform Latitude Spacing

Unlike regular lat/lon grids, Gaussian grids use **computed latitude positions**:
- `dj` field is always `null`
- Latitudes are Gaussian quadrature points
- Provides exact integration for spherical harmonics

### 2. Grid Extents

Gaussian grids extend nearly to the poles:
- `lat_first` ≈ +(90-ε)°  
- `lat_last` ≈ -(90-ε)°
- Where ε ≈ 0.5° for typical grids

### 3. Template Pairings

GDT 40 typically pairs with:
- **PDT 0**: Analysis/forecast products
- **PDT 2**: Derived forecast products
- **DRT 3**: Complex packing with spatial differencing (high compression)

### 4. Scanning Mode

Typical `scanning_mode` values:
- **0**: +i (eastward), -j (southward) — most common
- **64**: +i (eastward), +j (northward)

## Data Sources

### NOAA CORe Archive (Historical)

**Base URL**: `https://storage.googleapis.com/noaa-nws-ncep-core/grib/3hour/flx/YYYY/MM/`  
**Pattern**: `flx.YYYYMMDDHH.grb`  
**Example**: `flx.2024011500.grb` (10.5 MB, T254)

### NOAA GDAS (Operational)

**Base URL**: `https://nomads.ncep.noaa.gov/pub/data/nccf/com/gfs/prod/`  
**Pattern**: `gdas.YYYYMMDD/HH/atmos/gdas.tHz.sfluxgrbf000.grib2`  
**Example**: `gdas.20260724/00/atmos/gdas.t00z.sfluxgrbf000.grib2` (122 MB, T1534)
