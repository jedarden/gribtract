## Command Examples

Basic inventory:
```bash
wgrib2 file.grib2
```

Show DRT information:
```bash
wgrib2 -Sec5 file.grib2
```

Show packing mode:
```bash
wgrib2 -packing file.grib2
```

Show verbose packing details:
```bash
wgrib2 -v -packing file.grib2
```
