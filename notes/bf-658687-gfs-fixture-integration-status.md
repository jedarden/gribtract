## Appendix: Technical Details

### Gaussian Grid Mathematics
Gaussian grids use Gaussian quadrature points for optimal numerical integration in weather models. The latitudes are not equally spaced but are the roots of Legendre polynomials.

**Key Parameters:**
- N = number of latitudes between pole and equator
- Total latitudes = 2N (includes both poles)
- Gaussian latitudes computed as roots of Legendre polynomial P_N(x)

For this fixture:
- N = 128 (number between pole and equator)
- Total latitudes = 256 (2N)
- Latitude spacing = irregular (Gaussian quadrature)

### GRIB2 Template Byte Layouts

**GDT 3.40 Key Octets:**
- Octets 31-34: Ni (number of longitude points) = 512
- Octets 35-38: Nj (number of latitude points) = 256
- Octets 47-50: latitude of first grid point = 89.4629°N
- Octets 56-59: latitude of last grid point = -89.4629°S
- Octets 60-63: longitude of last grid point = 359.297°E

**DRT 3 Key Octets:**
- Octets 12-21: Common packing header (R, E, D, N values)
- Octets 22-23: Group splitting and missing value management
- Octets 32-35: Number of groups (ngroups)
- Octet 48: Order of spatial differencing (1 or 2)
