
- Direct download available via NCEI interface

## URL Pattern for GFS 0.5 Degree Files

The complete URL pattern for accessing GFS 0.5 degree GRIB2 files:

```
https://nomads.ncep.noaa.gov/pub/data/nccf/com/gfs/prod/gfs.YYYYMMDD/CC/atmos/gfs.tCCz.pgrb2.0p50.fFFF
```

**Components:**
- `gfs.YYYYMMDD/` - Model run date (YYYY = year, MM = month, DD = day)
- `CC/` - Forecast cycle: 00, 06, 12, or 18 (UTC)
- `atmos/` - Atmospheric model data directory
- `gfs.tCCz.pgrb2.0p50.anl` - Analysis file (initial conditions)
- `gfs.tCCz.pgrb2.0p50.fFFF` - Forecast file (FFF = forecast hour: 000, 003, 006, ..., 384)

**File naming breakdown:**
- `gfs` - Model name
- `tCCz` - Cycle time (z = UTC/Zulu time)
- `pgrb2` - GRIB edition 2 format
- `0p50` - 0.5 degree resolution
- `fFFF` - Forecast hour (3-hour intervals from 000 to 384 hours)

**Additional resources:**
- Each GRIB2 file has a corresponding `.idx` index file for variable-level access
- File sizes: ~140-155 MB per forecast file

## Notes

- 0.5 degree resolution files are approximately 1/3 the size of 0.25 degree files (~140-155 MB vs ~500 MB)
- Forecast horizon extends to 384 hours (16 days) at 3-hour intervals
- Four model runs per day: 00Z, 06Z, 12Z, 18Z
- All data is in GRIB2 format (WMO-compliant)
- Index files (.idx) allow variable-level subsetting without downloading entire files
