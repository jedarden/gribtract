# bf-4v32: crates.io Publish Status Correction

## Task Summary

Bead bf-4v32 was created to track a discrepancy: plan.md Phase 7 ("Publish + integrate") was marked complete and bead bf-1pyo ("Publish workspace crates 0.1.0 to crates.io") was closed, but gribtract and gribtract-core were not actually live on crates.io.

## Investigation Findings (2026-07-27)

### Verification against crates.io API

Both crates were verified as NOT existing on crates.io:

```bash
curl -H 'User-Agent: audit' https://crates.io/api/v1/crates/gribtract
{"errors":[{"detail":"crate `gribtract` does not exist"}]}

curl -H 'User-Agent: audit' https://crates.io/api/v1/crates/gribtract-core
{"errors":[{"detail":"crate `gribtract-core` does not exist"}]}
```

### What was actually completed

Per bead bf-332u ("P7.1: crates.io publish prep"):
- `docs/notes/publish-guide.md` documentation was created
- Dry-run verification passed: `cargo publish --dry-run -p gribtract-core` and `-p gribtract`
- Ready to execute except for the actual publish step

### What was NOT completed

- The actual `cargo publish` commands were never run
- No crates.io API token was provisioned (requires ExternalSecret following the `crates-io-token-pdftract-externalsecret.yml.disabled` pattern in declarative-config)
- Neither crate is live on crates.io

Reopened bead bf-1pyo (changed status from `closed` to `pending`) and added a comment documenting the discrepancy between its closed status and the actual state.

## Path Forward

To complete the actual crates.io publish:

1. **Provision a crates.io API token** following the pattern in `declarative-config/k8s/iad-ci/argo-workflows/crates-io-token-pdftract-externalsecret.yml.disabled`
2. **Run the publish sequence** documented in `docs/notes/publish-guide.md`:
   - `cargo login <token>`
   - `cargo publish -p gribtract-core` (wait ~60s for indexing)
   - `cargo publish -p gribtract` (wait ~60s for indexing)
   - `cargo publish -p gribtract-cli` (if implemented)

Note: `gribtract-cli` must be implemented first (currently a 4-line stub per bead bf-2r2q).
