## ❌ Files with DRT=2/3 (Complex Packing) - NOT Suitable

The following NOAA models use **complex packing** (DRT=2/3), NOT simple packing (DRT=0):

### GFS 0.25° Global Forecast System
- **Packing:** `grid_complex_spatial_differencing` (DRT=2)
- **Coverage:** Global (includes CONUS but not CONUS-specific)

### NAM CONUS (North American Mesoscale)
- **Packing:** `grid_complex_spatial_differencing` (DRT=2)
- **Coverage:** CONUS high-resolution nest

### RAP CONUS (Rapid Refresh)
- **Packing:** `grid_jpeg` (DRT=2 with JPEG compression)
- **Coverage:** CONUS 13km AWIPS grid

## Key Finding

**NOAA's DRT=0 files are exclusively found in analysis products (RTMA/URMA), not forecast model output.** The agency uses simple packing for mesoscale analyses but complex packing for all forecast model runs.

## Best Sources for DRT=0 CONUS Data

1. **RTMA 2.5 CONUS** - Hourly analyses, 2.5km resolution, DRT=0 confirmed
2. **URMA 2.5 CONUS** - Hourly analyses, 2.5km resolution, DRT=0 confirmed
