## What was actually wrong
`conus_drt0.json` was hand-authored: it was missing the `_provenance` and
`parser_version` root fields that the schema (memory:golden-json-schema) and the
other two goldens carry. Its decoded values/metadata were otherwise identical to
the reference decoder's output.

## Fix
Regenerated `conus_drt0.json` with the reference decoder:
```
python3 scripts/gen_golden.py tests/corpus/small/conus_drt0.grib2 conus_drt0 \
    --output-dir tests/corpus/golden
```
This adds the missing schema fields with **zero** semantic change to the values
(270..373, 104 points, GDT=0 PDT=0 DRT=0) the tests compare — the regenerated
`Dense` array and all metadata are identical to the prior hand-authored content
(JSON number formatting aside: ints now vs floats before, both parse to the same
f64).
